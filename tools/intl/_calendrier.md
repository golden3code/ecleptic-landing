Les guides publiés avant le 15/12 proposent seulement d'être prévenu : rien n'invite à s'inscrire avant l'ouverture. Chaque guide sort le même jour dans les 7 langues, donc les liens hreflang sont complets dès le premier jour.

## À l'ouverture de la vague 1 (15/12/2026)

Dans `tools/build_articles.py`, passer à `True` les langues ouvertes dans `COACH_INTL_LIVE` (es, de, it, nl ; pt seulement si l'on accepte que les coachs brésiliens, vague 3, arrivent sur la console avant l'ouverture du Brésil).
